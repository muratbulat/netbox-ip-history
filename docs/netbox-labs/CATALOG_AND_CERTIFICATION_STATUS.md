# Catalog and Certification Status

## Plugin Catalog

The catalog draft is complete in `PLUGIN_CATALOG_SUBMISSION.md`. Submission is not automatic. The current official NetBox Plugin Certification Program guidance requires a public GitHub repository, public PyPI package URL, plugin config name, maintainer name, contact email, source repository, and PyPI entry. The PyPI URL is now available; the public contact email remains a placeholder until submission.

## Certification

`CERTIFICATION_SUBMISSION.md` and `certification-email.md` are drafts only. Certification is release-specific and remains an external NetBox Labs decision. The repository does not claim to be certified. PyPI identity, NetDev Slack identity, real NetBox matrix evidence, screenshots, and NetBox Labs co-maintainer coordination remain outstanding.

Official reference checked: https://github.com/netbox-community/netbox/wiki/Plugin-Certification-Program
